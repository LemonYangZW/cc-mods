# desktop-copy

为 Claude Code 终端界面带来接近桌面客户端的复制体验。

在终端里，Claude Code 会把表格里较长的单元格拆成多行显示，长文本折行时还会带上悬挂缩进。用鼠标选中时，要么根本选不到一整个单元格，要么复制出来夹着硬换行、缩进和界面符号（`●`、`⎿`、`▎`）。desktop-copy 解决这两个问题。

## 功能

### 复制单元格和整张表

Claude 回复里的表格由 mod 自己绘制，样式与原来相同，鼠标悬停时出现复制按钮：

- **单元格**：悬停时右下角出现 `Copy` 按钮，点击即可复制整个单元格的纯文本，不管它折成了几行。markdown 标记会去掉，`<br>` 变成换行。窄列只显示图标。
- **整张表**：悬停时下边框上出现 `TSV` 和 `MD` 按钮。`TSV` 可以直接粘贴进电子表格，`MD` 复制表格的原始 markdown。
- **`/copy-cell`**：在单元格里选中几个字，再运行这个命令，即可复制整个单元格。

表格在窗口里放不下时，以及在其他界面（桌面应用、VS Code）里，仍由 Claude Code 按原样绘制。

### 干净的鼠标复制

用鼠标选中文字时，Claude Code 会在松开鼠标时复制。选区稳定后，desktop-copy 会把它和所在消息的源文本对照，把修正后的文本写回剪贴板：

- 终端折行拆开的行拼回一行，源文本里有空格的地方补一个空格；
- 去掉悬挂缩进和界面前缀（`●`、`⎿`、`▎`、`❯`、`│`）；
- 保留真实的换行、空行、列表符号、嵌套列表缩进和代码缩进。

适用于 Claude 的回复、你自己的消息、命令输出和 Bash 输出。每次修正后，状态栏会短暂提示。对不上源文本的内容保持 Claude Code 复制的原样。

如果在修正写入之前就粘贴到了 Claude Code 自己的输入框里，粘贴的内容同样会被修正。

**`/copy-debug`** 显示当前选区 Claude Code 实际复制了什么（换行、行首空格、制表符都会标出来），以及 mod 会把它修正成什么。

## 环境要求

- 支持插件 hooks 模块的 Claude Code（在 2.1.301 上测试过）。
- 终端全屏界面（`CLAUDE_CODE_NO_FLICKER=1`），这时鼠标由 Claude Code 自己处理。悬停按钮和复制修正都依赖它。
- 复制和完成图标需要 [Nerd Font](https://www.nerdfonts.com/)。没有的话图标会显示成方块，但按钮上仍有 `Copy`、`TSV`、`MD` 文字。

## 安装

```sh
npx cc-mods install desktop-copy
```

或者在 Claude Code 终端会话的输入框里：

```
/plugin install desktop-copy --marketplace LemonYangZW/cc-mods
```

卸载用 `npx cc-mods uninstall desktop-copy`。更新方法和其他安装方式见[仓库 README](../../README.zh-CN.md#快速开始)。

## 已知限制

- Claude Code 原生的选中即复制无法拦截，修正后的文本会在选区稳定后约半秒才替换进剪贴板。在这段时间内粘贴到其他应用，得到的是未修正的文本。
- 跨越已绘制表格多行的鼠标选区按显示原样复制，请改用单元格和表格按钮。
- 状态栏和命令的提示目前是简体中文。

## 原理

mod 会记下它绘制过的每条消息的源文本。把选区压缩成只剩可见字符，再到同样压缩过的源文本里定位。之后根据源文本，判断相邻两行之间是真实换行还是折行，以及这一行实际缩进了多少。
